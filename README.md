# Legal Site Template

This package is a reusable legal site template for new/existing brands


## Requirements

 - PHP 8.4.27


## Setup

 - Clone the repository
```bash
git clone git@github.com:meynard-peakroi/legal-site.git
```
 - Edit the .env file variable values
```bash
API_URL=https://xxx.domain.com/
API_KEY=pk_live_xxxxxx
```

 - Install the packages via composer
```bash
composer install
```
